## Sobre o Projeto

- **Hero** — apresentação com animação e efeito typewriter
- **Sobre** — bio, stack de tecnologias e download do currículo
- **Skills** — tecnologias organizadas por categoria
- **Experiência** — histórico profissional com timeline
- **Projetos** — carrossel com layout dividido e galeria de imagens
- **Educação** — formação acadêmica e cursos/certificados em abas
- **Contato** — links diretos para email, LinkedIn e GitHub



## Stacks

- **Framework:** Next.js 16 (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4
- **Animações:** CSS puro via IntersectionObserver
- **Imagens:** next/image com otimização automática
- **Deploy:** Vercel



## Rodando localmente

```bash
# instalar dependências
npm install

# servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.


## Estrutura

```
src/
├── app/          # layout, página principal, estilos globais
├── components/   # seções e componentes da UI
├── data/         # dados dos projetos
└── hooks/        # useInView (IntersectionObserver)
public/           # imagens, CV em PDF
```
